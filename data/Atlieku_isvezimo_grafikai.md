## Konvertavimas į app formatą

```javascript
const CONTAINERS = [
  { type: "MIXED",     id: "52-MK-036668", operator: "UAB Kauno svara", anchor: "2026-08-04", intervalDays: 14, until: "2027-07-20" },
  { type: "PACKAGING", id: "52-P-22781",   operator: "Ekonovus",        anchor: "2026-08-04", intervalDays: 21, until: "2027-03-23" },
  { type: "GLASS",     id: "52-S-24716",   operator: "Ekonovus",        anchor: "2026-08-04", intervalDays: 84, until: "2027-07-06" },
];

// Next pickup on or after `now`. Returns null past the operator's published range.
function nextPickup(c, now) {
  const anchor = new Date(c.anchor);
  const ms = c.intervalDays * 864e5;
  const steps = Math.max(0, Math.ceil((now - anchor) / ms));
  const next = new Date(anchor.getTime() + steps * ms);
  return next > new Date(c.until) ? null : next;
}
```

Alternatyva — jei reikia tikslaus operatoriaus sąrašo be ekstrapoliacijos, naudoti aukščiau esančias lenteles kaip statinį `PICKUPS` masyvą.
